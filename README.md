# churn-prediction-

Data Science with Python Thesis 
Customer Churn Prediction using demographic data based on
Machine Learning Techniques.
◼ Performed Exploratory Data Analysis (EDA) with Python, visualizing
customer behavior patterns using bar charts, histograms, and pie charts.
◼ Cleaned and preprocessed data, applying techniques such as One-Hot
Encoding, Standard Scaler, and addressing data imbalance using SMOTE.
◼ Built and evaluated machine learning models (Logistic Regression,
SVM, Random Forest) by comparing their performance using metrics such as
Accuracy, Precision, Recall, F1-score, and Confusion Matrix.
◼ Enhanced interpretability of predictions using Local Interpretable
Model-Agnostic Explanations (LIME).
